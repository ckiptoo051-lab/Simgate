📥 Installation Guide

1️⃣ Download APK

Get the latest signed APK from the Releases section on GitHub.

2️⃣ Enable Unknown Sources

Go to Settings > Security > Enable "Install from Unknown Sources" if needed.

3️⃣ Install Application

Open the APK file and follow the installation prompts.

4️⃣ Launch SimGate

Open the app and proceed with authentication setup.

5️⃣ Grant Permissions

Accept all required permissions when prompted by the app.

6️⃣ Start Gateway

Tap "Start Gateway" to begin sending and receiving SMS.

🔐 Required Permissions

Essential Permissions

  • SEND_SMS - Send text messages via your SIM
  • READ_SMS - Read incoming and sent messages
  • RECEIVE_SMS - Receive incoming SMS messages
  • READ_PHONE_STATE - Monitor phone status and SIM information
  • POST_NOTIFICATIONS - Show app notifications (Android 13+)

Optional but Recommended

  • Ignore Battery Optimizations - Keep app running in background
  • Autostart on Boot - Automatically restart gateway on device reboot
